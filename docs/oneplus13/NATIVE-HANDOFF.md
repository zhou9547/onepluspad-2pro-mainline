# 原生显示参数的 RAM 交接

2026-10-24。本轮仅做离线移植，无手机命令、重启、RAM启动或分区操作。

## 本次修复

之前 `desktop/prepare` 只复制 SPR 参数到新根目录，没有保留候选版本标记和
匹配的 `start-native-display`。这会使切根后的诊断材料不完整。对照原项目
`initramfs/init-ncm` 在切根前准备新 `/run` 的做法，增加专用的数据交接库，
使用手机自己的候选、校验和与 RAM 生命周期，不复制平板的硬件参数。

`native.py` 生成四行 `ONEPLUS13_NATIVE_HANDOFF_V1` 清单：格式版本、内核
release、176字节SPR参数的SHA256、已替换内核占位符的助手SHA256。
交接前检查四个文件齐全、版本一致、两个哈希正确，再写入 RAM overlay。
旧候选缺少完整清单时拒绝交接，不静默继承。普通诊断候选没有这些文件时
不写任何原生参数。

目标使用 `usr/lib/firmware`，兼容 Ubuntu 的 `/lib -> usr/lib` 布局，并拒绝
其他目标父目录的符号链接、已有目标和部分输入。助手只保存在新 `/run`
下的私有目录中，权限600，不执行、不注册服务、不调用modprobe。
复制失败会阻止切根；原有诊断和恢复期限继续生效。

## 验证范围

新增主机 shell 测试覆盖正常/缺省交接，以及十种缺件、版本、长度、哈希
异常、目标冲突和条件调用中的复制失败。完整测试套件53项通过。

QEMU 观察器在切根后运行同一交接库，使用仅存在于 `/run` 夹具中的合成
字节验证 merged-/usr、文件权限、目标符号链接、损坏数据与旧清单拒绝。
这些合成字节不是有效的面板参数，不提交给内核。观察器还检查真实根目录
未获得原生参数、显示模块未加载。成功必须出现
`ONEPLUS13_NATIVE_HANDOFF_OFFLINE_OK`，之后才接受桌面交接和超时恢复。
[Actions40056382745](https://github.com/zhou9547/onepluspad-2pro-mainline/actions/runs/40056382745)
已通过，源码为 `166de20f636837fecc95b7c50eb04842543739f7`。下载后复核
新initramfs中的实际脚本与源码相同，日志按序出现新增复制验收、桌面交接、
180秒截止和实际重启。53项测试在ARM64 runner也通过。
现有OTA代理测试增加handler完成事件，修复接收线程早于计数更新的竞态；
没有修改OTA提取逻辑。手机900秒期限仍保留，本轮没有在手机运行。

本轮使用已经验证的 d624154c 内核与2957513a根文件系统，固定字节重用，
只重新生成和测试initramfs，不重复编译未修改的内核，也不刷新根文件系统。

## 厂商批处理的进一步对照

补充取得并按Git blob核对固定厂商提交的 `dsi_display.c`、`dsi_ctrl.c`、
`dsi_ctrl_hw_cmn.c`、`dsi_ctrl.h`。厂商默认FETCH_MEMORY路径累积命令到
末尾才kickoff；非末尾不会unprepare，时钟/电源与命令引擎保持到该组完成。
安全会话的FIFO和non-embedded路径会强制末尾标记，双DSI broadcast还有
240字节附近的提前flush条件，因此平板路径的行为不能直接当作手机依据。

生产序列150包的13个名义单链路批组，按真实MSM头和4字节对齐机械计算，
合计1216字节、最大312字节；最大单包payload100字节，加头104字节，低于
厂商256/1024字节embedded阈值。唯一120ms等待在已提交的组边界，没有
悬挂组中的显式等待。上述结果是固定模式、非安全、单DSI默认路径的布局
计算，不是实际传输耗时或PLL证据，也没有验证原生面板电气行为。

主线 `dsi_cmd_dma_add()` 每包都置LAST位，随后立即DMA并等待；仅复制
0x40 flag不能补齐资源持有、批组锁和失败清理。下一步应审查显式整组提交
接口，使一组在同一次锁和资源生命周期中完成，而不是在无关调用间保留
没有归属的pending状态。本轮没有更改内核发送路径。

## 仍然关闭的功能

这只是私有材料跨切根的数据交接，不是原生显示激活。助手仍拒绝桌面会话，
原生桌面打包仍关闭。未加入自动加载、忽略modprobe策略或重启GDM的动作。
下一步继续审查厂商13个DSI批组、主线逐条DMA路径、PLL取整和显示资源接管，
再实现可复核的显式激活路径。不能把复制验证或QEMU通过当作物理显示验收。
