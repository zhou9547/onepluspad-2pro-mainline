# WiFi 历史联网通过与当前回退

机主记忆正确。run66 真实通过了扫描、目标发现、密码认证、DHCP/默认路由和
证书校验的 HTTPS（HTTP200，TLS verify0）。原启动镜像和 rootfs 仍保留，
本轮重新计算哈希与当时合同一致，历史结果没有作废。

后来为了核对手机专用固件、板级输入和射频功率策略，切换到了
stock-platform-isolated 镜像。该镜像禁用了无线 DT 节点及模块加载，
initramfs/rootfs 均不含 WCN7860 固件。因此当前无法联网，是主动隔离造成的
功能回退，不能描述成同一套已联网系统突然坏掉。

run66 保留为历史联网功能基线，但其参考无线输入不等于手机专用 RF 策略
已验收。当前隔离镜像、新驱动源码和未来固件候选分别记录。只有当前具体
候选再次通过扫描、认证、取址/路由及证书校验 HTTPS，才记为当前 WiFi 通过。
不同镜像的各项通过记录不能拼成一套已经全部可用的系统。

本轮已完成原生 ARM64 SAR 协议/实际驱动测试，以及完整 ath12k/WiFi7
编译和组合链接（Actions40319212570）。五个精确手机 WLAN 文件已在主机
inactive 目录准备；新完整内核构建为 Actions40320714130，使用已发布手机
base 与固定 WiFi overlay，构建本身不操作手机。功率策略与当前候选联网
仍未通过，详见 WIFI-DRIVER-DELIVERY-20261026.md。

本次核验没有恢复旧候选、刷写、改分区或新增 RAM 启动。旧停止账本保留；
历史成功不能自动取得新一次试机授权，也不应为了证明“有动作”而重复启动。
