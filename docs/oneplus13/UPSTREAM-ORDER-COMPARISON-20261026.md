## 参考实现带来的调整

原项目传感器要求是“原机registry先于attach”，然后以真实加速度计数据作为数据面门槛；并没有证明所有可选DSP探测文件都必须存在。手机余下30条请求继续完整记录，不能造文件/去`#`或声称文件服务全通；同时也不能未经论证把TPPE/CHRE缺失扩大成所有基本传感器的永久前置条件。先实现只允许SUID查询和单次属性读取、拒绝测量/订阅命令的独立探测入口，离线通过后再审查发现阶段。

音频参考其“麦克风先、扬声器后”的进程，分离WCD capture链路与AW speaker保护。相机没有可照搬的完成实现。新上游内核`085b395a...`的已检查wifi7 ops仍无set_sar_specs，CAMSS匹配表未包含sm8750项；不能通过直接更新手机内核来宣称这两个门禁消失。当前手机内核/rootfs不变。

本轮只做来源比较和离线适配，不执行原项目刷写、重分区、切槽或持久安装步骤。机主随后追加5小时，真机窗口现至2026-10-26北京时间20:25:13；原截止仅作历史记录，必须人工配合的验证留后。
