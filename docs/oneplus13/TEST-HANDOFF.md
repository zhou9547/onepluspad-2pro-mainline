# 下一次现场验收

当前手机授权仍是只读。本文件是后续现场测试门槛，当前没有执行试启动或刷写。
所有候选均为实验性RAM环境；保留原厂Android和完整恢复输入。

1. 先验收原300秒默认诊断候选的ABL交接、USB NCM/ACM、内存保护和自动返回。
   依据实际内核/USB日志判断，Fastboot返回OKAY不能证明进入了内核。
2. 再准备主机172.16.13.2/24和固定分块服务器，使用与交付rootfs SHA完全一致的
   校准RAM桌面候选。确认SHA通过、systemd/GDM启动、物理块设备只读且Android
   分区未挂载。桌面候选900秒截止；真实死锁与恢复仍需现场独立退路。
3. 独立native候选验收AA569固定120Hz原生输出：实际像素/色彩/DSC完整画面、
   TE/frame完成、错误日志和反复启停。GDM active或模块加载不等于看到了画面。
4. 独立touch候选验收S3910协议、完整触摸区域、多个触点及按下/移动/释放；
   不把触控与未经验证的原生显示电源/复位同时更改。
5. 独立WLAN候选先确认硬件major、QMI芯片/板号与实际BDF/regdb选择，再核对认证、
   SAR和真实收发。9个匹配固件文件不是这些项目的替代证据，不使用平板板号。

各独立项真机通过后才合并设备树，并回归冷启动、USB和恢复。完成这些门槛后，
再确认持久存储布局/账户/恢复方案，制作和测试手机专用安装路径。

公共根文件系统没有默认密码；GNOME初始设置需要现场输入。USB分块服务器只提供
根文件系统和开发通道，不会替主机配置互联网共享，USB/WLAN真实联网仍待测试。
